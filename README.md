# 📊 Trader Behavior vs Market Sentiment Analysis

> An exploratory data analysis project investigating how trader profitability, trading activity, trade size, and directional bias vary across Bitcoin Fear and Greed market sentiment regimes using Hyperliquid trading data.

---

## 📌 Project Overview

This project analyzes the relationship between **trader behavior** and **Bitcoin market sentiment** by combining historical trading data from the **Hyperliquid platform** with the **Bitcoin Fear & Greed Index**.

The analysis focuses on understanding how trader behavior changes between **Fear** and **Greed** periods, with particular attention to:

- Trader profitability
- Win rate
- Trading frequency
- Average trade size
- Long/short directional bias
- Trader activity segmentation
- PnL consistency
- Next-day profitability

The goal is to identify behavioral patterns that can help explain how traders perform under different market sentiment conditions.

---

## 🎯 Objectives

The project aims to answer the following questions:

1. How does average trader PnL differ between Fear and Greed periods?
2. Does trading activity change with market sentiment?
3. Does trader directional bias change between Fear and Greed?
4. How do frequent and infrequent traders perform across sentiment regimes?
5. How does PnL consistency vary across traders?
6. Can trader-level features be used to create a next-day profitability label?

## 🧹 Data Preparation

The analysis performs the following preprocessing steps:

- Loaded historical trading and sentiment datasets
- Checked dataset dimensions
- Checked missing values
- Checked duplicate records
- Converted millisecond timestamps into daily dates
- Converted sentiment dates into a consistent format
- Aligned trading data and sentiment data by date
- Focused the analysis on **Fear** and **Greed** sentiment periods

## 📈 Trader-Level Metrics

Daily trader metrics were created by grouping the trading data by **Account** and **Date**.

| Metric | Description |
|---|---|
| Daily PnL | Total closed PnL generated by a trader during the day |
| Trades per Day | Number of trades executed during the day |
| Average Trade Size | Mean USD trade size |
| Buy Ratio | Proportion of trades executed on the BUY side |
| Win Rate | Percentage of trader-days with positive PnL |

These metrics provide a common framework for comparing trader behavior across sentiment regimes.

## 👥 Trader Segmentation

The project further segments traders to investigate whether trading style is associated with performance.

### 1. Frequent vs Infrequent Traders

Traders are segmented using the median number of trades per day.

```text
Trades per Day
      │
      ├── Above / Equal to Median → Frequent
      │
      └── Below Median → Infrequent
```

The resulting groups are compared using:

- Average PnL
- Win Rate
- Market sentiment

### 2. Consistent vs Inconsistent Traders

Trader consistency is evaluated using the standard deviation of daily PnL.

```text
Lower PnL Variation  → Consistent
Higher PnL Variation → Inconsistent
```

This provides an additional perspective on the relationship between PnL stability and trader behavior.

## 🔬 Next-Day Profitability Feature

A next-day profitability label was engineered at the trader level.

```text
Current Trading Day
        │
        ▼
Trader Features
(PnL, Trade Frequency, Buy Ratio)
        │
        ▼
Next-Day PnL
        │
        ▼
Profitability Label
0 = Not Profitable
1 = Profitable
```

This creates a foundation for potential future predictive modeling.

> Note: The current project focuses on exploratory analysis and feature/label creation rather than training a predictive model.

## 💡 Key Findings

Based on the analyzed dataset:

- Average trader PnL differs between Fear and Greed sentiment periods.
- Fear periods show higher average daily PnL in the analyzed data.
- Trading frequency changes across sentiment regimes.
- Greed periods show stronger long-side directional bias based on the average Buy Ratio.
- Trader activity and PnL consistency can be further examined through frequency and consistency segmentation.

These findings describe patterns observed in the analyzed dataset and should not be interpreted as universal market behavior.
